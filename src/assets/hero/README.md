# Hero photo

Put one large landscape photograph here (JPG, PNG, WebP or AVIF, at least 2400px wide) that you have the
rights to use. The build turns it into AVIF and WebP at several widths and uses it as the home-page hero.
If several files are here, the first by name is used. With no photo, the hero falls back to the
forest-green contour design.

Set its description in `site.config.ts` (`heroPhotoAlt`).
